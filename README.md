# Трекер задач

Простой трекер: Python 3.11 (только стандартная библиотека) + статический фронтенд.

## Запуск

```bash
python server.py
```

Открыть в браузере: **http://localhost:8000/app.html**

Сервер слушает `0.0.0.0:8000`, статику отдаёт из своей папки, база — `tracker.db`
рядом со скриптом (создаётся автоматически при первом запуске).

## Интерфейс

- **День / Неделя** — переключатель вида в шапке. Неделя: семь дней с понедельника,
  у каждого свой список и счётчик «выполнено X из N»; кнопка «Незакрытые →» переносит
  незакрытые задачи этого дня на следующий.
- **Поиск** — поле над списком, ищет по тексту без учёта регистра: в дне — по текущему
  дню, в неделе — по всем семи дням.
- **Фильтр приоритета** — «Все / Высокий / Средний / Низкий», работает вместе с поиском.
- **Архив** — кнопка в шапке. «Убрать выполненные» отправляет закрытые задачи в архив,
  оттуда их возвращает кнопка «Вернуть».
- **Перенести на завтра** — переносит незакрытые задачи дня на следующий день
  и увеличивает счётчик «перенос ×N».

## API

| Метод  | Путь                              | Тело / параметры                       | Ответ                            |
|--------|-----------------------------------|----------------------------------------|----------------------------------|
| GET    | `/api/tasks?date=YYYY-MM-DD`      | `q` — поиск по тексту (необязательно)   | массив задач на день             |
| GET    | `/api/tasks?from=…&to=…`          | `q` — поиск по тексту (необязательно)   | массив задач за период           |
| POST   | `/api/tasks`                      | `{text, date, priority}`               | созданная задача                 |
| PATCH  | `/api/tasks/<id>`                 | `{text?, done?, date?, priority?}`     | обновлённая задача               |
| DELETE | `/api/tasks/<id>`                 | —                                      | `{ok: true, id}`                 |
| POST   | `/api/tasks/move-unfinished`      | `{date}`                               | `{moved: N, date: <след. день>}` |
| GET    | `/api/archive`                    | —                                      | массив архивных задач            |
| POST   | `/api/tasks/archive-done`         | `{date}`                               | `{archived: N, date}`            |
| POST   | `/api/tasks/<id>/restore`         | —                                      | задача, возвращённая из архива   |

`q` ищет по подстроке без учёта регистра; `date` равносилен `from=date&to=date`;
архивные задачи в выдачу `/api/tasks` не попадают.

Коды ответов: `200` — успех, `400` — неверные данные (`invalid date`,
`from and to are required`, `from is after to`), `404` — задача не найдена.

Таблица `tasks`: `id TEXT PRIMARY KEY, text TEXT, date TEXT, priority TEXT,
done INTEGER, moved INTEGER DEFAULT 0, archived INTEGER DEFAULT 0, created_at INTEGER`.

## Файлы

- `server.py` — сервер и API.
- `app.html` — интерфейс (fetch к API).
- `manifest.json` — манифест PWA (имя `BartolomewTT`, `standalone`, иконки 192/512).
- `sw.js` — service worker: оболочка и манифест из кэша, `/api/*` всегда из сети.
- `icons/icon-192.png`, `icons/icon-512.png` — иконки приложения.
- `index.html` — прежняя версия на localStorage (оставлена как есть).
- `tracker.db` — база (появляется после запуска).

## Телефон и установка на iPhone

Вёрстка: одна колонка, отступы 12 px, кнопки и чекбоксы не ниже 44 px,
поля ввода 16 px (iOS не зумит), снизу отступ под `env(safe-area-inset-bottom)`.
Вид «Неделя» на телефоне — вертикальный список карточек дней, на экране шире 1000 px —
три колонки.

Установка на iPhone:

1. Открыть `http://<адрес-машины>:8000/app.html` в Safari.
2. «Поделиться» → «На экран Домой».
3. Запускать с иконки — откроется без адресной строки (`display: standalone`).

Телефон и компьютер должны быть в одной сети; Windows Firewall должен разрешать
`python` для частных сетей, иначе телефон не откроет страницу. Service worker
работает только в защищённом контексте: на `http://localhost` — да, на `http://<IP>`
— нет, поэтому с телефона офлайн-кэш не включится (установка на домашний экран
при этом работает).
